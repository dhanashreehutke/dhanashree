# Artificial Intelligence Internship Projects

This repository contains machine learning projects completed for the Naviotech Solution AI Internship.

## Projects Included

### 1. Customer Churn Prediction (`Copy_of_Customer_Churn_Prediction_using_ML.ipynb`)
- **Objective:** Predict customer churn using demographic and subscription service features.
- **Algorithms:** Logistic Regression, Decision Tree, Random Forest, XGBoost.

### 2. Diabetes Prediction (`Diabetes_Prediction.ipynb`)
- **Objective:** Predict the likelihood of diabetes in patients based on diagnostic measurements.
- **Algorithms:** Support Vector Machine (SVM).

## Environment & Libraries
- Python 3.x
- NumPy, Pandas, Matplotlib, Seaborn, Scikit-learn, XGBoost
